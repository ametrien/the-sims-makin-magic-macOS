# Эксперимент: виртуальный рабочий стол Wine

Идея: запускать игру внутри виртуального стола Wine — он для macOS обычное окно
с заголовком, его можно двигать и сворачивать. Правок в коде не требует, только реестр:

```
[HKEY_CURRENT_USER\Software\Wine\AppDefaults\Sims.exe\Explorer]
"Desktop"="SimsDesk"

[HKEY_CURRENT_USER\Software\Wine\Explorer\Desktops]
"SimsDesk"="800x600"
```

**Результат: не работает, и причина принципиальная.** В режиме виртуального стола
Wine обрабатывает смену режима экрана сам и возвращает успех — вместо отказа
`DISP_CHANGE_BADMODE`. Из-за этого не срабатывает наша эмуляция 16-битного режима
в `ddraw7_SetDisplayMode`, игра остаётся в 32 битах и завершается.

То есть виртуальный стол и эмуляция режима несовместимы по построению. Чтобы
совместить, эмуляцию пришлось бы включать не по факту отказа системы, а явным
признаком (переменной окружения или ключом реестра).
